FULL GITHUB + FFMPEG-KIT ASLI
1. Upload semua file ke Github repo irvanjpyt
2. Actions > Build APK > Run workflow
3. Download APK dari Artifacts
4. APK ini jalanin ffmpeg beneran di dalam: baca folder, kunci depan, full acak, concat copy no encode, gabung audio, simpan ke /storage/emulated/0/[FOLDER]/[FOLDER]_GAS[n]_[JAM].mp4
5. Code ffmpeg disembunyi di MainActivity.java, buyer tidak bisa copy dari dalam APK.
